
#  Orchestrating Data Pipelines in Microsoft Fabric

##  Objective
To automate ingestion and transformation workflows using Microsoft Fabric pipelines.

---

##  Step-by-Step Process

### Step 1: Create Pipeline
1. Open **Data Factory in Fabric**
2. Click **New → Pipeline**
3. Add Dataflow activity
4. Add Notebook activity

---

### Step 2: Configure Dependencies
- Dataflow runs first
- Notebook runs after ingestion

---

### Step 3: Schedule Pipeline
1. Add trigger (time-based or event-based)
2. Monitor pipeline execution

---

## Outcome
- Automated end-to-end data pipeline
- Successful orchestration of ingestion and transformation tasks


---

##  Key Learnings
- Pipelines orchestrate complex workflows
- Supports scheduling and monitoring
- Similar to Azure Data Factory
